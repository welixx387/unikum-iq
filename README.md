# Уникум IQ

IQ-тест из 25, 35 или 50 заданий, в котором задания не повторяются — ни у
одного человека, ни между разными людьми. Каждое задание собирается
алгоритмом в момент старта теста, получает цифровой отпечаток и проверяется
на уникальность. После теста — оценка по шкале IQ и разбор: какие
способности получились хорошо, какие стоит подтянуть, и каждое задание с
верным ответом и объяснением.

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга (статический сайт, папка `dist/`):

```bash
npm run build
```

`npm run build:single` дополнительно собирает всё в один файл
`artifact/index.html` (удобно для превью).

`npm run check` — самопроверка генераторов: создаёт по 2000 заданий каждого
типа и уровня и проверяет варианты ответов, тексты и частоту совпадений.

### Деплой на Vercel

Создайте в Vercel новый проект из этого репозитория — фреймворк (Vite) определится сам, дополнительные настройки не нужны.

## Задания

Шесть категорий, в каждой несколько видов заданий и пять уровней сложности:

| Категория | Виды заданий |
|---|---|
| Числовые ряды | прогрессии, чередования, растущие разности, квадраты и кубы, суммы предыдущих, простые числа, два ряда вперемешку |
| Визуальные матрицы | матрицы 3×3 в духе Равена: форма, количество, размер, заливка, цвет и поворот, от одного до четырёх правил одновременно |
| Пространственное мышление | мысленное вращение фигур из клеток, зеркальное отражение, поворот узора, наложение прозрачных карточек |
| Логика | силлогизмы с выдуманными словами, упорядочивание по условиям, рыцари и лжецы |
| Буквенные коды | ряды букв и пар букв, буквы с числами, шифры (сдвиг, обратный порядок, чередование) |
| Количественное мышление | числовые таблицы, уравнения с символами, лишнее число, текстовые задачи |

Правильность ответов проверяется программно: силлогизмы — перебором всех
возможных «миров», упорядочивание и рыцари — перебором всех раскладов,
числовые таблицы — проверкой, что никакое другое простое правило не даёт
другого ответа, лишнее число — проверкой, что никакое другое свойство не
выделяет другое число.

## Почему задания не повторяются

1. **Генерация.** Тест собирается из случайного 128-битного зерна
   (`crypto.getRandomValues`). Числа, фигуры, выдуманные слова и правила
   каждый раз новые.
2. **Отпечаток.** Для каждого задания строится 128-битный хеш его
   содержания — условия без учёта порядка вариантов ответа. Одинаковые по
   сути задания дают одинаковый отпечаток.
3. **Проверка на устройстве.** Все выданные на устройстве отпечатки хранятся
   в браузере, поэтому одному человеку задание не повторится никогда, а
   внутри одного теста задания всегда разные.
4. **Проверка между людьми.** Если подключён общий реестр (см. ниже), каждый
   отпечаток атомарно «занимается» в базе с первичным ключом. Если такое
   задание уже кому-то выдавалось, сайт тут же генерирует замену. Так
   повтор исключён и между разными людьми.

Без общего реестра сайт работает полностью в браузере: разные люди получают
разные задания за счёт огромного числа вариантов, но строгую гарантию «ни
у кого и никогда» даёт только реестр.

### Глобальная уникальность заданий (Supabase)

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor → New query**, вставьте содержимое
   `supabase/iq-test.sql` и нажмите **Run**.
3. Скопируйте `.env.example` в `.env.local` и вставьте
   `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (Project Settings → API).
   При деплое задайте те же переменные в настройках хостинга.

В базе хранятся только хеши выданных заданий — никаких ответов и личных
данных. Если реестр временно недоступен, тест всё равно запускается в
локальном режиме, и экран подготовки честно показывает, какая проверка была
выполнена.

## Как считается IQ

Используется модель Item Response Theory (3PL): у каждого задания есть
трудность (по уровню), дискриминация и вероятность угадать (1 / число
вариантов). Способность θ оценивается методом EAP, а IQ = 100 + 15·θ.
Рядом с результатом показывается погрешность — стандартная ошибка оценки.
Это ориентировочный онлайн-тест, а не клиническая диагностика.

## Структура

- `src/engine/generators/` — генераторы заданий по категориям
- `src/engine/test.ts` — план теста, отпечатки и проверка уникальности
- `src/engine/registry.ts` — локальная история и общий реестр
- `src/engine/scoring.ts` — оценка IRT, шкала IQ и анализ
- `src/components/` — интерфейс: главная, экран теста, результаты, графики
- `scripts/check-generators.ts` — самопроверка генераторов
